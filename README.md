## 🧪 Getting Started

### Prerequisites
- Java 17+ JDK
- Maven or Gradle (depending on project)
- JUnit 5 for testing

### Clone & Build
```bash
git clone https://github.com/Soumyad0670/Java.git
cd Java/ProjectA
mvn clean test      # Or "./gradlew test" if using Gradle
````

## 🧩 Usage Examples

### 💳 Running “Banking System” (ProjectA)

```bash
cd Java/ProjectA
mvn exec:java -Dexec.mainClass="com.soumyad.banking.Main"
```

*Interact via console: create accounts, perform deposits/withdrawals, view statements.*
